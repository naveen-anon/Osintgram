# Osintgram 🔎📸

**Osintgram** is an open-source OSINT (Open Source Intelligence) tool for Instagram.  
It provides a command-line interface (CLI) to collect and analyze **public Instagram data** for research, investigations, and cybersecurity analysis. 1

> ⚠️ **For Educational and Ethical Use Only**  
> Do **not** use this tool to violate privacy, terms of service, or local laws. Only gather **public data** or data you are authorized to collect.

---

## 🚀 Features

Osintgram offers an interactive shell to perform intelligence gathering on a target’s Instagram profile by nickname. You can extract:

- 📍 Profile information (bio, username, follower/following counts)  
- 👥 Followers and followings data  
- 📷 Media info (photos, stories, hashtags)  
- 📊 Metadata (likes, comments, location)  
- 📂 Download media and profile pictures  
- ✉️ Emails and ☎️ phone numbers (publicly available insights only)
